# 麦门省钱助手（mcd-saver）

> 基于**麦当劳 MCP** 与 WorkBuddy Skill 体系的**全渠道比价**省钱助手 —— 抖音/美团报个数，官方渠道算到分，总账 AI 来算。
>
> 本项目为「麦当劳程序员节创意开发大赛」参赛作品，由参赛者独立开发，非麦当劳官方产品。

## 项目介绍

点一份麦当劳，你可能要打开抖音看团购、打开美团比外卖、打开小程序领券——三个 App 来回切换，还要在脑子里算配送费、券门槛、有效期、核销规则。**麦门省钱助手**把这个过程收敛成一句话：**官方渠道（App/小程序）由 AI 通过麦当劳 MCP 精确计算到分，抖音/美团价格你报个数，总账 AI 对齐口径后算清，直接告诉你"去哪个渠道买"。**

```
跨平台总账比价（外部报价 + 官方精算） → 每日领券 → 多券试算 → 最优方案下单 → 积分到期提醒与变现
```

核心亮点：

- **跨平台总账比价**——外部团购券按"规格 / 就餐方式 / 总价"三重口径对齐，过滤"便宜但送不了"的假性优惠，价差小于 2 元时自动叠加便利性分析（直下直送、攒积分、可退款）；
- **官方渠道精算**——下单前自动用 `calculate-price` 对"原价 vs 每张可用券"逐一试算，统一含配送费口径后推荐应付总价最低的方案，并提示"帮你省了多少钱"。

## 功能特性

| 工作流 | 功能 | 核心能力 |
|--------|------|----------|
| E 跨平台比价 | 抖音/美团报价录入 + 官方渠道 MCP 精算 → **规格/就餐方式/总价三重口径对齐** → 总账对比表 + 推荐去哪个渠道买 | 招牌能力，终结三 App 手工比价 |
| A 每日领券 | 查麦麦省可领券 → 一键领券 → 到账确认 | 零成本囤券，为比价备弹药 |
| B 省钱点餐 | 四种就餐方式（到店/得来速/麦乐送/团餐）选店 → 门店可用券查询 → **多券比价矩阵试算** → 最优价下单 | 官方渠道精算引擎（E 的内核） |
| C 积分变现 | 积分账户查询 → **即将过期积分主动提醒** → 积分商城比价推荐 → 一键兑换 / 抽奖 | 让积分不闲置 |
| D 资产盘点 | 卡包券（按到期优先排序）+ 积分全景 | 一句话看清家底 |
| 活动雷达 | 当月营销活动日历查询 | 活动上新及时领券 |

## 安装方法

### 第一步：申请麦当劳 MCP Token（前置条件）

1. 打开[麦当劳 MCP 开放平台](https://open.mcd.cn/mcp)，点击右上角【登录】，手机号验证登录；
2. 点击右上角【控制台】→【激活】，同意服务协议后获得 MCP Token（一键复制）。

### 第二步：在 WorkBuddy 中配置麦当劳 MCP 连接器

1. 打开 WorkBuddy，进入左侧边栏【专家·技能·连接器】→【连接器】页签；
2. 点击右上角【自定义连接器】→【配置 MCP】；
3. 粘贴以下 JSON（**务必将 `YOUR_MCP_TOKEN` 替换为自己的实际 Token**），点击【保存】：

```json
{
  "mcpServers": {
    "mcd-mcp": {
      "type": "streamablehttp",
      "url": "https://mcp.mcd.cn",
      "headers": {
        "Authorization": "Bearer YOUR_MCP_TOKEN"
      }
    }
  }
}
```

4. 回到【自定义连接器】，将 `mcd-mcp` 开关【启用】。

> 本仓库所有配置仅使用 `YOUR_MCP_TOKEN` 环境变量占位符，不含任何真实 Token。

### 第三步：安装本 Skill

```bash
# 方式一：克隆仓库
git clone https://github.com/<你的用户名>/mcd-saver.git
# 将 Skill 目录复制到 WorkBuddy 用户级技能目录
cp -r mcd-saver/mcd-saver ~/.workbuddy/skills/
```

或直接下载本仓库，把 `mcd-saver/` 文件夹放入 `~/.workbuddy/skills/` 目录，重启对话即可生效。

## 使用示例

安装完成后，在 WorkBuddy 对话框中直接说出诉求即可：

| 你说 | 助手做什么 |
|------|-----------|
| 「抖音上巨无霸套餐 29.9，帮我看看哪个渠道买最划算」 | 触发工作流 E：官方渠道 MCP 精算 → 录入抖音报价 → 规格就餐方式总价三重对齐 → 总账对比表 → 告诉你去哪个渠道买 |
| 「帮我领一下麦当劳的券」 | 触发工作流 A：查麦麦省可领券 → 一键领取 → 汇报到账情况 |
| 「我想点个巨无霸套餐，怎么买最划算」 | 触发工作流 B：确认就餐方式 → 定位门店 → 查菜单与门店券 → 多方案试算 → 推荐最优价并说明省了多少 |
| 「我有多少积分？有没有快过期的」 | 触发工作流 C/D：查积分账户 → 提醒即将过期积分 → 给出积分商城兑换建议 |
| 「这个月麦当劳有什么活动」 | 查活动日历 → 汇报进行中/即将开始的活动 → 引导领券参与 |
| 「看看我有什么券能用」 | 已选门店时查门店可用券；未选门店时先定位再查 |

**跨平台比价示例（工作流 E 摘录）**：你说「抖音巨无霸套餐 29.9，美团外卖 28.5，我要外卖」后，助手输出类似总账：

```
渠道              到手总价   说明
─────────────────────────────────────────────
麦乐送官方最优    ¥39.0     含配送费，可用"满39减8"券，直接送上门
美团外卖          ¥37.5     ¥28.5 + ¥9 配送费（以实际结算价为准）
抖音团购 29.9     ——        仅到店核销，你要外送，出局 ✗
─────────────────────────────────────────────
👉 推荐：美团外卖省 1.5 元；若差价在 2 元内，官方渠道
   可攒积分且免核销，也值得考虑
```

**官方渠道比价示例（工作流 B 摘录）**：选定商品后，助手会输出类似方案对比：

```
方案              应付总价   说明
─────────────────────────────────────
原价下单          ¥45.0     基线方案
麦香鸡券方案      ¥37.5     满39可用 ✓ 已满足门槛
板烧券+凑单薯条   ¥38.5     需加购3.5元凑单，总价反超，不推荐
─────────────────────────────────────
👉 推荐：麦香鸡券方案，帮你省 7.5 元
```

## 目标用户

- **跨平台比价党**：下单前习惯在抖音、美团、小程序之间反复横跳，希望"报个数就得到买哪个渠道的结论"；
- **麦当劳高频消费者（"麦门"信徒）**：每周多次点餐，单次优惠累积价值高；
- **价格敏感型学生与职场人群**：预算有限，希望每次下单都用最优价格；
- **积分囤积党**：有大量麦当劳积分但常常忘记兑换，需要到期提醒与变现建议；
- **懒人用户**：不想研究 App 里散落的券规则，一句话完成"领券+比价+下单"。
