# 跨平台比价知识库（抖音 / 美团 / 官方渠道）

## 定位说明

麦当劳 MCP 只覆盖官方渠道（App/小程序：麦乐送、到店取餐、积分商城等）。抖音、美团的价格**无法通过 MCP 获取**，一律由用户口述录入；但**外部平台团购产品的规则特征相对稳定**（核销方式、时效、叠加规则），是比价结论成立与否的关键知识。本文件是工作流 E 的执行依据。

核心原则：**外部价格只录不猜**。用户提供多少信息，就用多少信息；未确认的字段标注"以券面规则为准"，绝不臆测。

## 各渠道特征对照

| 渠道 | 产品形态 | 常见限制 | 比价要点 |
|------|----------|----------|----------|
| 抖音团购 | 单品券 / 套餐券 / 直播专属券 | 到店核销为主；有效期较短（常见 7–30 天）；部分限时段（午市/晚市/工作日）；通常不可与官方优惠叠加 | 满足到店需求时可参与比价；外送需求下直接出局 |
| 美团 | 外卖订单 / 到店团购 | 外卖须另计配送费与包装费（高峰期上浮）；到店团购同样需核销 | 外卖场景须含配送费后与麦乐送到手价对比；到店团购与抖音同类 |
| 官方渠道（App/小程序） | 优惠券 / 麦金卡 / 早餐卡 / 积分兑换 | 可配送到家；消费累积积分；未支付可取消；券有效期各异 | 由 MCP 精确计算到分，是总账比价的**基准侧** |

> 以上为各渠道常见特征，具体以用户提供的券面规则与平台实际结算价为准。

## 口径对齐三规则（工作流 E4 执行细则）

### 规则 1：规格对齐

- 官方套餐有"大 / 中 / 小"规格差异（主餐份数固定，薯条与饮料尺寸变化），外部团购的"套餐"未必同规格。
- 逐项对照清单：主餐是否同款 → 薯条尺寸 → 饮料尺寸 → 是否额外含小食/甜点。
- 规格不一致时的处理顺序：**优先折算**（按官方单点价折算差额后比价）→ 折算不了则**建议加购对齐**（如外部套餐含中薯，官方算大薯，用差价修正）→ 无法对齐时明确告知"两者不是同一个东西"，避免假性比价。
- 用 `query-meal-detail` 获取官方套餐的精确组成作为对照基准。

### 规则 2：就餐方式对齐

- 比价前必须确认用户就餐方式：到店 / 外送 / 都行。
- **到店核销类团购券（抖音/美团团购）**：用户需要外送时直接出局，不参与比价——这是最常见的比价陷阱，"便宜 5 块但根本送不了"。
- **外送场景比价**：美团外卖报价 + 配送费 + 包装费 vs 麦乐送到手价（MCP 试算已含配送费），两边都必须是"送到手里的总价"。
- **"都行"场景**：全渠道参与，但推荐时注明"此方案需到店"作为决策因子。

### 规则 3：总价口径

- 所有方案统一折算为**到手总价**：商品金额 − 优惠 + 配送费/包装费 + 为凑门槛加购的金额。
- 禁止混比：券面价 ≠ 到手价；抖音挂单价 ≠ 核销到手价（可能有打包费）。
- 官方渠道的到手总价以 `calculate-price` 试算结果为准（金额分转元），不手算。

| 渠道 | 到手总价 | 规格 | 就餐方式 | 限制条件 | 结论 |
|------|---------|------|----------|----------|------|

## 推荐决策规则

1. **先过滤**：不满足用户就餐方式的方案直接出局并说明原因（如"抖音券只能到店核销，你要外送所以不能用"）。
2. **再比价**：剩余方案按到手总价升序排列。
3. **小价差裁决**：最优两方案价差 < 2 元时，输出便利性对比后由用户定夺——
   - 官方渠道优势：可直接下单配送、消费累积积分、未支付可取消、无需到店核销；
   - 外部平台优势：价格低、有时有平台补贴；
   - 给出倾向性建议（如"差 1.6 元，建议官方渠道省事还能攒积分"），但明确把决定权交给用户。
4. **风险提示**：对最终推荐方案必须复述其限制条件（有效期 / 可用时段 / 核销方式 / 是否可叠加），避免用户买完才发现用不了或过期。

## 常见场景速查

- **用户要外送，抖音有低价到店团购** → 团购券出局；改为"麦乐送到手价 vs 美团外卖含配送费价"对比。
- **外部套餐规格更小/更大** → 按 `query-meal-detail` 的官方组成折算差额后再比，或建议加购对齐。
- **用户"到店都行，哪个便宜去哪"** → 全渠道总账对比 + 小价差便利性提示。
- **用户没提外部价格，只问"怎么买最划算"** → 走工作流 B 官方渠道精算，完成后主动反问："要不要报个抖音/美团的价格，我帮你算跨平台总账？"（引导进入工作流 E，但不强推）
- **用户报的外部价格明显异常**（如比官方基线低 70% 以上） → 提醒确认是否为"第二份半价""需另购""新人专享"等限定条件，避免录入误导性报价。
- **外部报价含糊**（"抖音好像二十多"） → 追问具体价格与套餐内容，拿不到就不纳入对比表，只做官方渠道推荐。
